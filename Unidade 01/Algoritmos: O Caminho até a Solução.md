O processo de resolução de problemas computacionais exige desde a análise conceitual até a implementação prática.

• Depois de aplicar os pilares do pensamento computacional: 

1. Decomposição

2. Identificação de padrões

3. Abstração

4. Elaboração de algoritmos 

Tranformamos para a solução real.

• Um algoritmo é a sequência lógica de passos para resolver um problema ou executar uma tarefa e serve como a base para qualquer programa de computador

• Para que o algoritmo seja compreendido e executado por um computador, ele precisa ser escrito em uma linguagem de programação.

---

🔨 **Por que Usar uma Linguagem de Programação?**

A linguagem de programação são algoritmos abstratos que são convertidos em instruções operacionais interpretáveis pelos sistemas computacionais.

• A linguagem de programação é o meio pelo qual se transforma algoritmos em instruções compreensíveis pelo computador. Enquanto o algoritmo pode ser escrito em linguagem natural, fluxograma ou pseudocódigo, somente a linguagem de programação permite a execução real da solução.

• Programar é dar vida ao algoritmo.

• É transformar raciocínio lógico em ação automatizada.

---

🔨 **Linguagem C:**

• C é uma linguagem estruturada, possuindo variáveis, funções, estruturas de controle e operadores.

• C Permite um acesso mais direto aos recursos do computador, como memória e dispositivos.

**A linguagem C é amplamente utilizada em:**

• Sistemas operacionais como o Linux

• Sistemas embarcados

• Automação industrial e de processos
