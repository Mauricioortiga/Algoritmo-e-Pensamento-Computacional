Exercício 1 — Apresentação pessoal

Objetivo: praticar variáveis, tipos de dados e exibição de informações no console.

Enunciado: crie um programa JavaScript que armazene as informações de um aluno e apresente os dados no console.

Dados a armazenar:

Nome do aluno

Idade

Curso

Semestre atual

Requisitos:

Utilize let ou const para declarar as variáveis.

Utilize o padrão camelCase nos nomes das variáveis.

Utilize console.log() para exibir as informações.

Apresente cada informação em uma linha separada.

Exemplo de resultado esperado:

Plaintext

Nome: Carlos
Idade: 20
Curso: Sistemas de Informação
Semestre: 3
